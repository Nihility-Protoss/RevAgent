# RevAgent

## 主要目的

本项目旨在**低模型能力、低技术能力**的条件下，实现**人在回路（HITL）环境下的样本分析**。系统面向 Qwen 27B 这类本地部署模型，通过分阶段多 Agent 协作、黑板式上下文持久化与人工审查，降低样本分析对模型能力和使用者技术经验的要求。

当前主要面向 Windows PE 恶意样本静态分析。输入为 IDA 导出的字符串、导入导出表、函数索引，以及可选的反编译和反汇编文本，不直接执行可疑二进制文件。

## 基础结构

系统基于 LangGraph 编排，整体流程为：**预提取 → 快速定性 → 行为定型与函数筛选 → 调度与人工审查 → 函数级深度分析 → 综合报告**。

- `main.py`：运行入口，负责参数解析与分析流程启动。
- `graph.py`、`graph_nodes.py`：定义各阶段节点、流转关系和人工审批环节。
- `workers/`：包含各阶段的 Worker 定义、提示词和专项分析知识。
- `tools/`：提供输入文件加载、黑板读写、检查点和 Token 统计等工具。
- `state.py`：定义图状态及各 Agent 的结构化输出模型。
- `config.py`、`config.yaml`：管理模型、路径和分析参数。
- `data/input/`：存放 IDA 导出的样本分析数据。
- `data/output/`：作为黑板保存各阶段的提取结果、完整产物、摘要和元数据，支持阶段间通信与断点续跑。

## 下一步更新目标

- **优化 Agent 间交互方案**：改进各阶段和 Worker 之间的信息传递与协作方式，提升低模型能力条件下的分析稳定性和质量。
- **可视化优化**：改进分析流程、任务进度、人工审查和分析结果的展示。
